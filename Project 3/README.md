# Project 3 | Vulnerability Governance and Secure Change

**QASIC Cyber | Tinu Adewumi | Luma Retail Group fictional capstone case study**

How should leaders prioritise limited remediation capacity against the most material business exposure? This project considers asset criticality, exploit context, CVE and CVSS research, risk-based prioritisation, exceptions and validation of remediation.
