# Project 1 | Cyber Control Assurance and Remediation

**QASIC Cyber | Tinu Adewumi | Fictional capstone case study**

How can leadership gain confidence that key security controls are operating effectively and that gaps are being addressed? This project considers host hardening, firewall governance, security monitoring, evidence quality, accountability and risk-based remediation.
